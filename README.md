# Структуры данных — консольные реализации

**Прежнее название репозитория:** `3Sem1Lab`.

Реализации динамического массива, связных списков, стека, очереди и AVL-дерева на C++ с консольным интерфейсом.

**Примерный период реализации:** октябрь 2025. Период указан по истории Git и отражает основную работу над проектом.

## Структура

Отдельные реализации находятся в `massive.cpp`, `onelinked.cpp`, `twolinked.cpp`, `stack.cpp`, `queue.cpp` и `AvlTree.cpp`. `main.cpp` содержит консольный интерфейс, `Makefile` — правила сборки.

## Сборка

Требуется компилятор C++17 и Make.

```bash
make
./ds
```
